# Kelivo RP 版 · 快速上手（写给朋友）

> 这版 App 专门为角色扮演/陪聊改造过。**大部分设置都不用碰**，照下面三步走就行。

## 1. 导入角色（30 秒）

「角色库」现在满大街都是入口，随便挑一个顺手的：

- **聊天顶栏的 🎭 面具图标**（最显眼）
- **侧边栏底部的 🎭 按钮**（头像那一排）
- **侧边栏顶部的「新功能」卡片**（点卡片即可，看完点 × 不再显示）
- **聊天输入框「＋」菜单 → 角色库**
- 助手页顶部的大横幅卡 / 右上角魔法棒（老入口还在）

进去之后：

1. 点右上角**上传**图标，选一张 SillyTavern 角色卡 PNG（社区下载的那种）
2. 导入完成。**点一下卡片**就是使用这个角色——开场白、人设、世界观、记忆全部自动配好

> 不用 PNG 角色卡也行：正常新建助手、填人设，一样能聊。但导入角色卡会自动开启下面所有记忆能力。

## 2. 让它不忘事（已自动配好）

导入的角色自动开启了：

- **记忆 + 自动整理**：聊过的重要剧情、你说过的设定（比如耳洞、习惯）会被记下来，跨对话也记得
- **角色专属记忆**：每个角色的记忆互相隔离，不会串戏
- **前情提要**：就算你开了「上下文消息数限制」，被裁掉的剧情也会以摘要形式注入，角色知道自己失忆了什么
- **防漂移契约**：每次回复前，角色都会收到「保持你一开始的热情和语气」的指令——**解决聊久了从火热变高冷的问题**

想手动确认它记住了什么：设置 → 日志查看器 → 上下文日志，能看到实际发给模型的全部内容。

## 3. 让它开口说话（可选）

1. 设置 → 文字转语音（TTS），添加一个 TTS 服务（OpenAI / Gemini / Azure 等任一）并选为默认
2. 助手编辑页 → **语音** 区块，给这个角色单独选服务和音色
3. 设置里打开「自动朗读助手回复」（或点消息旁的播放按钮手动听）

给不同角色配不同音色，听起来就是两个不同的人在说话。

## 4. 聊天里的小功能

- **旁白**：角色回复里 `*星号包裹的部分*` 会显示成气泡外的灰色斜体小字，像剧本的舞台指示
- **沉浸模式**：长按聊天页顶部的角色名，或点输入框「＋」菜单里的「沉浸模式」→ 隐藏顶栏，全屏沉浸；点右上角小箭头退出
- **重新生成**：对回复不满意就长按消息重新生成，多个版本可切换

## 常见问题

**Q：它把我说过的事忘了？**
问的时候带上关键词（比如「还记得运动会我说的事吗」）。如果还是想不起来，去上下文日志看看那件事有没有被写进记忆条目；没有的话再说一遍，下一轮就会被记下。

**Q：角色变得高冷/像客服？**
新版本已注入防漂移指令。如果还出现，长按那条回复重新生成，或直接告诉它「保持你一开始的热情」——这个反馈也会被记进记忆。

**Q：想要两个角色在同一对话里互动？**
在做了（群聊模式），先蹲一个后续版本。
